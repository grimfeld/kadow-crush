🍓 Kadow Crush

A lightweight match-3 puzzle game — built fresh for the web

Project summary & implementation report — June 2026

What it is

Kadow Crush is a match-3 puzzle game in the same family as Candy Crush. The player swaps neighbouring fruit tiles to line up three or more of a kind; matched fruit bursts off the board, the tiles above tumble down to fill the gaps, and fresh fruit drops in from the top. Chains of lucky drops can trigger satisfying combos.

It is a fresh, deliberately lightweight rebuild of our existing Unity-based Kadow Crush. The goal was a fast-loading, mobile-first version that keeps the core fun while shedding the weight and complexity of the full product.

How a round plays

  • The board: a grid of fruit tiles (8 rows × 7 columns), with five fruits — strawberry, blueberry, green apple, lemon, grapes.
  • The goal: collect a target number of two chosen fruits (currently 25 of each) before running out of moves.
  • The limit: 20 moves. A move is one swap; the chain reaction it sets off is free.
  • Winning & losing: meet both fruit goals in time to win; run out of moves first and the round is lost. Either way, a “Play Again” button starts a brand-new randomly generated board.

Special tiles

Bigger matches create power-ups, adding a layer of strategy beyond simple threes:

You match… You get… It does…
4 in a row a Striped tile clears an entire row or column when activated
5 in a row a Colour Bomb clears every tile of one fruit from the whole board

The experience

  • Mobile-first: designed for phones in portrait, scales crisply to any screen size and pixel density.
  • Two ways to play: swipe a tile in a direction, or tap one then tap its neighbour — whichever feels natural.
  • Juice: tiles pop and bounce, fruit shatters into coloured particles, and every action has a sound — all generated in the browser, no media files to download.
  • Always fair: the board never starts already-solved or in a dead end, and it quietly reshuffles itself if no moves remain.

By the numbers

~77 KB Download size (compressed)
0 External media files
< 0.5 s Build time

The entire game downloads in about 77 KB — roughly the size of a single small photo. There are no separate image or audio files to fetch: the fruit icons are standard emoji, the artwork is drawn by code, and the sound effects are synthesised live. That means near-instant loading, even on a weak mobile connection, and nothing to host or manage besides one small file.

How it was built (in plain terms)

The game is split cleanly into two halves, which is the key reason it is reliable and easy to extend:

  • The “rules brain” — knows everything about matching, scoring, the chain reactions and fairness checks, but knows nothing about how things look. Because it is self-contained, it can be tested automatically and trusted.
  • The “presentation layer” — takes a play-by-play description of what the rules brain decided and animates it on screen with the sounds and effects. It never second-guesses the rules.
Why this matters to the business: new fruit, new goals, new power-ups or visual themes can be added without risking the core game logic — and the logic is covered by automated tests, so changes are safe to ship.

Built to be re-skinned

Colours, fruit, labels and the background all live in one place, ready to be driven by a configuration file — mirroring how the existing Unity product is themed per campaign. A future pass can expose these as brand-customisable settings without touching the game itself.

Where it could go next

The current build is one self-contained level. The structure was chosen so that the following can be layered on without a rewrite:

Quick wins (small effort)

  • Score & combo points — reward big cascades, show a running score and a “nice combo!” flourish.
  • More power-ups — a wrapped/bomb tile from L-shaped matches; letting two power-ups combine for a bigger blast.
  • Goal variety — “reach a score”, “clear in under N seconds”, or single-fruit goals, instead of only collect-two.
  • Polish — a start screen, a countdown, screen shake on big clears, a “moves running low” warning.

Medium additions (more design work)

  • Multiple levels & a map — a sequence of hand-tuned or generated levels with rising difficulty, progress saved on the device.
  • Obstacles & blockers — locked tiles, ice, jelly to clear, crates — the staples that keep match-3 fresh for hundreds of levels.
  • Boosters & pre-game power-ups — items the player can spend to swing a tough board, a natural hook for monetisation or rewards.
  • Daily challenge / leaderboard — one shared random board per day, with scores compared between players.

Bigger bets (strategic)

  • Full brand-skinning pipeline — campaign-specific fruit, backgrounds, goals and copy driven entirely by configuration, matching the existing Unity product’s flexibility at a fraction of the weight.
  • Live events & seasons — limited-time themed boards, rewards and goals.
  • Lightweight multiplayer — head-to-head “same board, highest score” races.
Bottom line: a working, good-looking, near-instant-loading match-3 game is ready to demo today, built on a foundation designed to grow into the features above without starting over.
